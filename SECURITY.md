# Security Policy

## Reporting

Please report vulnerabilities privately through GitHub's security-advisory flow. Do not open a public issue containing tokens, receipt images, extracted personal data, or deployment details.

## Operator responsibilities

- Use independent, high-entropy values for every secret.
- Keep R2 buckets private.
- Restrict Cloudflare and GitHub administrator access.
- Rotate any token that appears in a log, screenshot, issue, or Git commit.
- Establish a retention/deletion policy before collecting real personal data.
- Review applicable privacy, tax, employment, insurance, and accounting obligations in your jurisdiction.

This software is not an accounting, legal, insurance, or security certification product.
